    Ошибки типа "AUTH"

    AUTH-001 - Вы не найдены в базе данных сервера!

    Описание:
    Ваш никнейм не найден в базе данных сервера.
    Возможные причины: - У вас отсутствует проходка. - Ваш никнейм был изменён.

    Место появления:
    🖥️ Сервер

    Возможные решения:
    - Проверьте правильность написания никнейма.
    - Приобретите проходку на официальном сайте LS:MP.
    - Если вы уверены, что проходка у вас есть — обратитесь в поддержку LS:MP через Discord.

    AUTH-002 - Система безопасности LS:MP остановила попытку входа!

    Описание:
    Ваш запрос на подключение к серверу был отклонён системой безопасности LS:MP, так как IP-адрес вашего последнего входа не совпадает с текущим.

    Место появления:
    🖥️ Сервер

    Возможные решения:
    1. Проверьте личные сообщения в Discord и подтвердите вход.
    2. Если сообщение не пришло: - Настройки пользователя Discord → Контент и общение → Права социальных взаимодействий. - В списке выберите LS:MP и включите Личные сообщения.

    AUTH-003 - У вас нет проходки!

    Описание:
    На вашем аккаунте нет активной проходки на сервер LS:MP.

    Место появления:
    🖥️ Сервер

    Возможные решения:
    - Приобретите проходку на официальном сайте LS:MP.
    - Следите за открытием бесплатных заявок на проходку в Discord LS:MP.

    AUTH-004 - Ошибка поиска

    Описание:
    Пользователь под вашим ID не найден в базе данных.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Проверьте, что вы используете тот же Discord-аккаунт, что и при регистрации.
    - Обратитесь в поддержку LS:MP, если недавно меняли аккаунт.

    AUTH-005 - Необходимо пройти верификацию!

    Описание:
    Ваш аккаунт не привязан к Discord. Необходимо пройти привязку через команду /verify на Discord-сервере LS:MP.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    1. Зайдите на Discord-сервер LS:MP.
    2. Найдите канал "Чат гостей".
    3. Используйте команду /verify ******.

    AUTH-006 - Код не найден!

    Описание:
    Указанный код не найден или уже истёк.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Проверьте правильность введённого кода.
    - Получите новый код и попробуйте снова.

    Ошибки типа "CMD"

    CMD-001 - Команда не найдена

    Описание:
    Данная команда не найдена или у вас нет к ней доступа.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Проверьте правильность написания команды.
    - Используйте /help для списка доступных команд.

    CMD-002 - Нет доступа

    Описание:
    У вас нет прав для использования команды.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Проверьте наличие роли для команды.
    - Обратитесь к администрации, если считаете, что доступ должен быть открыт.

    CMD-003 - Неверный синтаксис команды

    Описание:
    Неверный синтаксис или отсутствуют необходимые аргументы.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Воспользуйтесь подсказками Slash-команд Discord.
    - Введите /help для правильного синтаксиса.

    CMD-100 - У вас уже есть открытый билет

    Описание:
    Вы попытались создать новый тикет, но уже есть активный.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Дождитесь следующего набора.

    CMD-110 - Не удалось обработать запрос

    Описание:
    Ошибка обработки запроса. Попробуйте позже.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Повторите действие через несколько минут.
    - Если ошибка повторяется — обратитесь в поддержку LS:MP.

    CMD-111 - Этот билет уже занят

    Описание:
    Билет уже занят другим модератором.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Выберите другой тикет для обработки.
    - Обновите список активных тикетов.

    CMD-112 - Кнопки недоступны для вас

    Описание:
    Эти кнопки предназначены только для команды поддержки.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Не нажимайте чужие кнопки.
    - Ожидайте ответа поддержки.

    CMD-113 - Заявка уже рассмотрена

    Описание:
    Тикет уже был закрыт.

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    Возможные решения:
    - Проверьте список открытых тикетов.
    - Создайте новый тикет для возобновления обсуждения.

    Описание:

    Место появления:

    CMD-201 - Штраф не для вас

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    CMD-202 - Штраф оплачен или закрыт

    Описание:

    Место появления:
    💬 Discord (С.П.Р.У.Т)

    CMD-204 - У вас недостаточно средств

    Описание:

    Место появления:
